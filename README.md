 🌸 El Jardín de las Almas

Página web interactiva dedicada al significado simbólico de diferentes flores.

 Funciones

- Catálogo de flores
- Buscador
- Información sobre el significado de cada flor
- Sistema de flores favoritas
- Jardín personal
- Compartir flores mediante WhatsApp
- Mensajes personalizados
- Diseño responsive


- HTML5
- CSS3
- JavaScript

Objetivo

Crear una experiencia web interactiva que permita explorar
el significado de diferentes flores y crear un jardín personal.
